# About

Faust Pedal Kit is a collection of clean-room models of guitar and bass pedals, maintained by Joe Heffer on [GitHub](https://github.com/Joe-Heffer/faust-pedalkit). Bug reports, questions and contributions go to the [issue tracker](https://github.com/Joe-Heffer/faust-pedalkit/issues).

## Licence

- **Code** (the Faust DSP, build tools and tests) is [MIT](https://github.com/Joe-Heffer/faust-pedalkit/blob/main/LICENSE).
- **Documentation** (everything under `docs/`, including this site and the circuit research) is [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Every file's licence is machine-readable, following the [REUSE](https://reuse.software/) specification: each source file has an SPDX header, and `REUSE.toml` covers the rest.

## Citing

To cite the software or its circuit research, use the metadata in [`CITATION.cff`](https://github.com/Joe-Heffer/faust-pedalkit/blob/main/CITATION.cff). GitHub shows it as "Cite this repository" on the repository page.

## Trademarks and affiliation

The effects are independent models built from public information. They are not affiliated with, or endorsed by, any pedal manufacturer, and no proprietary code was used. Manufacturer and product names appear in the circuit notes only to identify the reference hardware, and remain the property of their owners.
