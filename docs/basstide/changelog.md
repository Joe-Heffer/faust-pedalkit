# BassTide changelog

Notable changes to BassTide. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the version, `declare version` in `src/basstide.dsp`, follows [Semantic Versioning](https://semver.org/). Each release is tagged `basstide-vX.Y.Z` (see [Releasing](../development/releasing.md)).

## [0.1.0]

First release (not yet released).

### Added

- Through-zero flanger for bass with Rate, Sweep, Follow, Glide, Feedback, Depth, Crossover and Level. The band below Crossover stays dry, and with Follow up each note starts its own sweep, which glides back to the zero point.
